## Правила

- **Только то, что есть в прочитанных главах.** Ничего не додумывай: ни внешность, ни возраст, ни мотивы. Если в тексте чего-то нет, поле оставляй пустым или пиши в `unknown`.
- **У каждого утверждения номер главы.** В абзацах — в поле `ch` этого абзаца.
- **Пиши литературно, своими словами.** Это текст музейной карточки: связные абзацы хорошим русским языком, без канцелярита, без списков фактов через точку с запятой. Не копируй предложения из новеллы; короткая цитата (до 10 слов) допустима только там, где важна точная формулировка.
- **Без спойлеров дальше главы 100.** Пиши то, что известно к сотой главе.
- Если новелла противоречит сама себе, выбери версию из более поздней главы и отметь расхождение в `unknown`.
- Наследие — это предмет, полученный за Решение Комнаты Проклятий (в тексте так и называется). Остальные вещи — предметы.

## Формат файла

Строгий JSON, без комментариев, UTF-8:

```json
{
  "id": "han-gain",
  "name": "Хан Гаин",
  "registry": [
    { "label": "Возраст", "value": "20 лет", "ch": 4 },
    { "label": "Занятие", "value": "…", "ch": 4 },
    { "label": "Как попал в отель", "value": "…", "ch": 1 }
  ],
  "about": [
    { "text": "Первый абзац сведений о госте: кто он, какой он, как держится.", "ch": [1, 4] },
    { "text": "Второй абзац: что он делает в команде, что о нём важно знать.", "ch": [14, 25] }
  ],
  "blessing": {
    "name": "Мудрость",
    "patron": "кто дал Благословение, если в тексте это сказано, иначе пустая строка",
    "text": [
      { "text": "Что это за Благословение и как гость его получил.", "ch": [1] },
      { "text": "Как оно работает на деле: что умеет, как гость им пользуется.", "ch": [22, 65] }
    ],
    "limits": [
      { "text": "Ограничение или цена, одной фразой.", "ch": [1] }
    ]
  },
  "legacies": [
    { "name": "Название наследия", "room": "102", "ch": [98], "text": "Абзац: за что получено, что делает, чего стоит владельцу." }
  ],
  "items": [
    { "name": "Название предмета", "source": "откуда взят: комната, лавка, награда", "ch": [22], "text": "Одно-два предложения: что это и как использовалось." }
  ],
  "unknown": [
    "Что о госте в главах 1–100 не сказано или расходится (с номерами глав)."
  ]
}
```

Требования к объёму:
- `registry`: 4–7 коротких строк, как графы анкеты (возраст, занятие, откуда, как попал в отель, особые приметы — только если они есть в тексте).
- `about`: 2–4 абзаца по 2–4 предложения.
- `blessing.text`: 2–3 абзаца; `limits`: 1–4 строки.
- `legacies` и `items`: всё, что числится за гостем к главе 100. Если ничего нет, пустой массив.
