## Каким должен быть каждый link

```json
{ "to": "kim-ari", "bond": "подруга", "text": "Друзья, доверяют друг другу. Он прислушивается к её советам.", "ch": [561, 634, 875] }
```

- `to` — id другого героя из списка выше.
- `bond` — одно-три слова, кто он для героя: «друг», «хён», «наставник», «коллега по Управлению», «союзница без доверия», «соперник».
- `text` — одна-две короткие фразы о самих отношениях: дружат, доверяют, опекают, спорят, боятся, уважают, недолюбливают, ревнуют, ждут друг от друга чего-то. **Без событий сюжета**: никаких номеров комнат, названий миров, боёв, смертей, «в Кубе он…», «в 305-м она…». Читатель должен понять, как они относятся друг к другу, а не что случилось.
- `ch` — 3–6 номеров глав этого этажа, где это отношение видно в тексте. Номера глав в `text` не пиши.
- 2–4 записи на героя, только самые важные отношения на этом этаже. Отношения меняются от этажа к этажу: на этаже 3 пиши, какими они стали к концу этажа 3.

Образец стиля — первый этаж, `src/data/guests/extra/han-gain.json`:
- «хён» — «Старший, который закроет собой. В бою работают парой.»
- «наставник» — «Сблизились в телестудии. Тренировки терпит, знаниям верит.»
- «союзница без доверия» — «Планы строят вдвоём, но до конца он ей не верит.»

## Только по тексту новеллы

- Каждое утверждение должно опираться на текст глав. Не додумывай. Если отношение в тексте не показано — не пиши его.
- Факты, которые важно не перепутать: Ким Муксон и Ким Ари — коллеги по Управлению, Ари старше. Пары героев смотри в тексте, а не по догадке.
- Источники:
  1. Сводки по героям: `docs/guests/floors/digest/f2/<id>.md` и `docs/guests/floors/digest/f3/<id>.md`. Там собраны сцены с номерами глав. Читай сводку героя целиком, не по диагонали.
  2. Сами главы, чтобы проверить каждое отношение: этаж 2 — `.chapters2/chNNNN.txt` (147–547), этаж 3 — `.chapters3/chNNNN.txt` (548–1168). Для каждой записи открой хотя бы две главы из `ch` и убедись, что там это видно.
- Нынешние `links` в файлах можно использовать как подсказку, с кем у героя есть связь, но их тексты не копируй.

## Проверка в конце
