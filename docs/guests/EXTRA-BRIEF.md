Сайт — музей по новелле «Побег из отеля с привидениями». В карточке гостя отеля появляются две новые вещи:

1. **Пометки на полях о других гостях** — короткие записи от руки: кто с кем пришёл, кто кому близок, кто с кем в ссоре. Каждая пометка указывает на другого гостя из восьми.
2. **Вклад** — за что сам отель признал гостя (Финальное Решение комнаты, спасительный Побег, особая награда).

## Формат файла

Строгий JSON, UTF-8, без комментариев:

```json
{
  "id": "kim-mukseon",
  "links": [
    { "to": "kim-ari", "text": "Пришли вместе, по одной копии билета.", "ch": [25] },
    { "to": "cha-jinchul", "text": "Не раз ссорились.", "ch": [66] }
  ],
  "merits": [
    { "title": "Финальное Решение", "room": "101", "text": "Одно предложение: что именно гость сделал.", "ch": [76, 77] }
  ]
}
```

- `links` — 2–4 пометки на гостя. `to` — id другого гостя из списка выше. `text` — одна короткая фраза до 10 слов, как запись портье от руки: сухо, по делу, без оценок и без слов «вероятно», «кажется». Только то, что прямо происходило в тексте.
- `merits` — 0–2 записи. Только то, что сам отель (система, Окно Статуса, объявление комнаты, Святилище) засчитал лично этому гостю. `title` — как это названо в тексте, 1–3 слова. `room` — номер комнаты или пустая строка. `text` — одно предложение. Если у гостя такого нет, пустой массив.
- `ch` — номера глав, где это сказано.

## Правила

- Только то, что прямо есть в тексте глав 1–100. Не уверен — не пиши запись. Никаких оговорок и предположений в значениях.
- Без спойлеров дальше главы 100.
- Создавай только файлы в `src/data/guests/extra/`. Остальные файлы, код и git не трогай.
- Команды терминала и скрипты не запускай: они запрещены. Пользуйся только чтением и записью файлов.
