## Формат файла

Строгий JSON, UTF-8, без комментариев:

```json
{
  "id": "han-gain",
  "rooms": [
    { "room": "101", "title": "Странная семья", "result": "Побег", "role": "", "note": "первая попытка", "ch": [10, 11] },
    { "room": "102", "title": "Особняк Ужасов", "result": "Побег", "role": "студент", "note": "", "ch": [24] }
  ],
  "deaths": [
    { "room": "102", "cause": "задушен ночью", "ch": [17] }
  ]
}
```

- `rooms` — по одной записи на каждый заход гостя в номер, по порядку событий. Повторный заход — отдельная запись, `room` пишется как `"101 Re"`.
  - `title` — название комнаты, как оно дано в тексте.
  - `result` — только одно из трёх слов: `Побег`, `Решение`, `Провал`. Так, как итог комнаты назван в тексте для этого гостя. Если гость в заходе не участвовал, записи нет.
  - `role` — кем отель сделал гостя в этой комнате (роль или облик: «дворецкий», «чёрный бык», «выпускник»), 1–3 слова. Если роли не было, пустая строка.
  - `note` — необязательная пометка до 5 слов (например, «в одиночку», «Финальное Решение за ней»). Иначе пустая строка.
- `deaths` — каждая смерть гостя внутри комнат, по порядку. `cause` — причина, 2–5 слов, без оценок.
- `ch` — номера глав, где это сказано.
