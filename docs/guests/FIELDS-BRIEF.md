# Задание: какие графы показать в карточке гостя

Сайт — музей по новелле «Побег из отеля с привидениями». У каждого из восьми гостей первого этажа есть карточка гостя отеля (как регистрационная карточка постояльца). Первый лист карточки — анкета: короткие графы «название — значение». Сейчас там почти пусто (возраст, занятие, семья, как попал в отель, комната), и это скучно.

Придумай, какие графы стоит показать в анкете, чтобы она была интересной именно для этой новеллы, а не анкетой из любого отеля.

## Что сделать

1. Вспомни или перечитай главы 1–100:
   `C:/Users/9325~1/AppData/Local/Temp/claude/52df69cb4dcb97c1/4e881869-68ea-4ad3-aebb-6cf873aeaa04/scratchpad/chapters/chNNNN.txt`
   (UTF-8; глав 2–7 и 19 нет). Особенно смотри, как сама новелла описывает гостей: окна статуса, характеристики, Благословения, то, как герои представляются и что отель о них «знает».
2. Посмотри, как устроена карточка: `src/archive/people/GuestCard.tsx` и готовый пример `src/data/guests/han-gain.json`.
3. Запиши предложение в файл `docs/guests/FIELDS.md`.

## Что должно быть в FIELDS.md

- Список из 8–12 граф анкеты. Для каждой: название графы (коротко, как в бланке), что в неё пишется, и почему она интересна для этой новеллы.
- Пометь, какие графы есть у всех восьми гостей, а какие только у некоторых.
- Для каждой графы — пример значения для двух-трёх гостей, взятый из текста, с номером главы.
- Отдельно: 5–7 граф, которые ты советуешь оставить в итоге, по порядку показа.
- Отдельно: если кроме анкеты стоит показать что-то ещё (например, шкалы характеристик, отметки о смертях, штампы пройденных комнат) — опиши, что именно и на каких данных из текста это держится.

## Правила

- Только то, что есть в тексте глав 1–100. Ничего не выдумывай. Без спойлеров дальше главы 100.
- Пиши по-русски.
- Создай только файл `docs/guests/FIELDS.md`. Файлы в `src/data/guests/` не трогай: их сейчас пишет другой исполнитель. Код и git не трогай.
- Команды терминала и скрипты не запускай: они запрещены. Пользуйся только чтением и записью файлов.
