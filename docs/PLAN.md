# Отель «Пионер» — план

## Цель (к чему идём)
**Интерактивный отель «Пионер» по новелле «Побег из отеля с привидениями».** Ты — гость:
- ходишь по отелю в 2D: лобби, коридоры, лифт, подвал, три этажа;
- каждая дверь — отдельный мир, который **захватывает интерфейс** и работает по механике своего проклятия;
- история открывается **по мере твоего чтения**: глава в гостевой книге и туман «□□□» не дают спойлерить;
- всё справочное (команда, боги, предметы, правила, хроника, связи) живёт **внутри отеля как документы**, а не как вики.

Готово, когда: открываешь сайт → стоишь в лобби → можешь пройти все три этажа, зайти в каждую комнату, почувствовать её проклятие и понять, чем она кончилась (если дочитал).

## Принципы
1. **Всё из книги.** Каждая механика опирается на факт из новеллы с номером главы.
2. **Ходишь в 2D, читаешь на страницах.** Атмосфера — в сцене, длинный текст — в «документах».
3. **Каждая комната непохожа на другие.** Своя тема, своё искажение, своя механика.
4. **Без спойлеров по умолчанию.** Всё после твоей главы скрыто, но открывается одним кликом.
5. **Только пересказ.** Текст глав не копируем.

## Слои системы
| Слой | Что делает |
|---|---|
| Данные | JSON: комнаты, заходы (Re), боги, персонажи, предметы, события, правила — у каждого факта глава |
| Движок отеля | 2D-сцены, гость, параллакс, переходы, лифт между этажами |
| Система | Окно статуса, Совет Мудреца, гостевая книга (глава), туман, шкала заражения |
| Движок комнат | Вход → «отель забирает тело» → тема и искажения → механика → выход в коридор; тумблер «Угроза / Итог» |
| Документы | Досье оперативников, бестиарий, правила, хроника, граф связей |

## Этапы

### Этап 0. Данные всей книги
- Извлечь все комнаты трёх этажей с повторными заходами, плюс подвал и передышки. Старый перевод до гл. 589, новый с гл. 590.
- Общие справочники: персонажи, боги, предметы (кто, где и когда получил, что спасло потом), правила отеля.
- Проверка: выборочно сверить с главами; сшить ID персонажей.
- **Результат:** `src/data/` покрывает 1–1168 главы.

### Этап 1. Каркас отеля
- 2D-движок: длинная сцена, гость-силуэт (← → / клик), параллакс, свет, переходы.
- Система: окно статуса, Совет Мудреца, гостевая книга, туман, шкала заражения (лечат лобби и 105, скука вызывает событие).
- Движок тем: одна комната = один модуль (тема + искажения + механика).
- **Результат:** можно ходить по пустому лобби и коридору; демо-комната показывает захват интерфейса.

### Этап 2. Первый этаж целиком (MVP)
- Лобби: стенд ключей со статусами по главе, стойка, дисплеи, лифт с «Побегом», вход в небо, Святилище.
- 105: гостиная, стол «Время обеда», личные комнаты → досье.
- Комнаты по порядку: **103** (образец) → 101 → 102 → 104 → 106 → 107.
- Повторные заходы (Re) — вторая версия той же комнаты.
- **Результат:** весь 1-й этаж проходим. Показываем друзьям, собираем отзывы.

### Этап 3. Документы
- Досье оперативников, бестиарий богов, правила, хроника по главам.
- **Граф связей** комнаты ↔ боги ↔ предметы.

### Этап 4. Остальной отель
- Подвал (бассейн, зоопарк, кемпинг…), 2-й и 3-й этажи, Время Вечеринок, Побеги.

### Этап 5. Полировка и публикация
- Арт (ИИ-фоны вместо силуэтов, если захотим), звук, мобильная версия, деплой.
