# Стек и устройство комнат

Решение принято после номера 102: комнаты делаются не длинной страницей на «базовом CSS», а как игра из сцен.

## Устройство комнаты

- **Комната = несколько сцен-маршрутов.** Например, `/archive/102`, `/archive/102/house`, `/archive/102/cards`. Каждая сцена занимает экран и содержит одно действие читателя.
- **Общая оболочка** (`layout.tsx` комнаты) живёт между сценами и не пересоздаётся: WebGL-холст, окно статуса, лента сцен, шторка-переход.
- **Прогресс** хранится в zustand с сохранением в `sessionStorage`, поэтому переживает переходы и перезагрузку вкладки.
- **У каждой сцены свой арт** (`public/art/<номер>/<сцена>.jpg`) и своя погода на холсте.

## Что за что отвечает

| Слой | Чем сделан | Файлы |
|---|---|---|
| Картинка и атмосфера | three + react-three-fiber, один полноэкранный шейдер | `src/stage/Stage.tsx` |
| Переходы между сценами | GSAP: шторки и заставка с названием (SplitText) | `src/stage/Curtain.tsx` |
| Игровые анимации в сценах | GSAP (`useGSAP`), таймлайны | в сценах |
| Мелкие состояния интерфейса | Motion | в сценах |
| Прогресс комнаты | zustand + persist | `src/archive/room<N>/state.tsx` |
| Вёрстка | Tailwind | везде |

### Шейдер сцены умеет

Арт во весь экран с подгонкой «cover», параллакс за курсором, перетекание между артами при смене сцены, дождь в три слоя, вспышки молний, ударную волну (в 102-й это колокол), хроматическую аберрацию, зерно, виньетку, затемнение под текст.

Управление из любого компонента:

```ts
useStage.getState().set({ image, rain, dark }); // арт и погода
useStage.getState().flash();                    // молния
useStage.getState().shock();                    // ударная волна
```

## Правила

- **«Меньше движения».** При `prefers-reduced-motion` холст рисует статичный кадр без дождя и вспышек, сцены меняются мгновенно, раздачи и заставки не проигрываются.
- **Арт, а не фигуры из CSS.** Фоны сцен генерируются (Higgsfield, GPT Image), сохраняются в JPEG до 1920 px.
- **Проверка WebGL.** В dev есть `window.__stageRender()`: рисует один кадр немедленно и возвращает состояние текстур. Нужен, когда вкладка в фоне и кадры анимации не идут.
- **Материал шейдера создаётся вручную** (`new THREE.ShaderMaterial`) и вставляется через `<primitive>`: если передать `uniforms` пропсом, react-three-fiber копирует объект, и обновления до шейдера не доходят.

## Что рассматривали и не взяли

- **View Transitions в Next 15** — экспериментальный флаг, поведение меняется между версиями. Свой переход на GSAP даёт полный контроль над заставкой.
- **PixiJS / вся комната на холсте** — длинные тексты книги плохо ложатся на canvas, комната делается намного дольше.
- **Длинная страница с прокруткой** (как 101-я) — быстрее, но ощущается сайтом, а не игрой.
